## 3. Findings

### LOW

### UI-D1-2026-10-12-01: 86f5a1a0a shipped the callback-registry check and the empty-`ImportAssets` skip without a test, and `Drop` still bypasses the registry
- **Severity**: LOW (test gap; the code itself is correct on reading)
- **Dimension**: Profile & Bridge (also Resource Navigator)
- **Profile**: both Scaleform profiles
- **Location**:
  - `crates/ui/src/player.rs:728-760` (`invoke_callback`)
  - `crates/ui/src/host.rs:405-407` (`prune_callback`)
  - `crates/ui/src/navigator.rs:564-570` (empty-URL `continue`)
  - `crates/ui/src/player.rs:795-803` (`Drop for SwfPlayer`)
- **Status**: NEW
- **Description**:
  - 86f5a1a0a changed three files (`host.rs`, `navigator.rs`, `player.rs`) and added no test.
  - `invoke_callback` now asks Ruffle's own registry (`context.external_interface.get_callback`) before invoking. It prunes a stale name from the bridge's set and returns `None`, so an AVM2 `addCallback(name, null)` unregistration no longer produces a `Null` that looks like a live callback's answer.
  - Nothing exercises that path. `grep` for `prune` or an unregistration test finds none in `crates/ui/src/{player,host,host/tests}.rs`.
  - Nothing exercises the empty-`ImportAssets` skip either. `navigator.rs` has no test with an empty URL.
  - `Drop for SwfPlayer` still calls `player.call_internal_interface(DESTROY_CALLBACK, [])` after checking only the bridge's name set. It does not use the registry check. If a movie unregisters its destroy hook, the drop path reaches Ruffle's "Calling unknown internal interface" warn.
  - This is inert: the return value is discarded.
- **Evidence**: `player.rs:797-800` (`has_callback` then `call_internal_interface`) against `player.rs:742-753` (registry check, prune, `return None`).
- **Impact**: no functional effect today. A refactor of the lock scope (the registry check and the invoke now share one `MutexGuard` held across `mutate_with_update_context`) or a Ruffle API change would regress silently.
- **Related**: 86f5a1a0a. The AVM2 fixtures in `crates/ui/testdata/` (Ruffle's `external_interface` SWFs) could host a test.
- **Suggested Fix**:
  - Add a host-bridge test that registers a callback in a real AVM2 movie, unregisters it with `addCallback(name, null)`, and asserts `invoke_callback` returns `None`, that `has_callback` is false afterwards, and that no `Null` leaks.
  - Add a `import_asset_paths_from_tags` test with an empty `ImportAssets` URL that asserts neither a path nor an error is produced.
  - Optionally route the `Drop` hook through the same registry check.

## 5. Verified clean this cycle

- **#5479 single decode.**
  - `normalize_scaleform_dialect` returns `Some(uncompressed)` on every CWS input (patched or not) and `Some` on FWS only when a record changed.
  - `decompress_swf` then takes the uncompressed copy path, so `SwfDecodeCounts { decompresses: 1 }` counts real work.
  - Pinned by `conforming_cws_returns_its_decode_with_an_untouched_body`.
  - Side effect: `PreparedMovie::data` is now the uncompressed file. Ruffle's own `from_data` therefore skips a second inflate.
- **#5456.**
  - The sprite descent stops at depth 1 (`MAX_SPRITE_DEPTH`).
  - A CWS body longer than its declared length is declined.
  - Pinned by `deeply_nested_sprites_do_not_overflow_the_stack`, `one_level_of_sprite_nesting_is_still_patched` and `cws_body_longer_than_its_declared_length_is_declined`. The SWF reader at the new pin (`2edfd97d`) still rejects the neither-MOVE-nor-HAS_CHARACTER form, so the shim stays needed.
- **#5274.** All 142 Skyrim entries are Measured. The arity pair `(min, max)` makes a mixed-arity name fail the sweep. The sweep ran with data: 0 uncataloged.
- **#5275 / #5528** (`dynamic_rgba.rs`).
  - The warn re-arm sits at the end of `record_pending_rgba_uploads`, so a skipped frame does not re-arm it.
  - `GrowthBackoff` gates growth before `create_host_visible` and counts frames only on would-be-attempt frames.
  - Its early `return Ok(())` also skips the re-arm.
  - Pinned by `growth_retries_back_off_during_a_failure_episode`, `growth_gate_sits_before_the_allocation` and `a_submitted_skip_frame_does_not_rearm_the_episode_warn`.
- **#5409.**

- **500fcb8ca.** `shutdown_discarding_egui_frame` uses egui 0.36's sanctioned drop.
